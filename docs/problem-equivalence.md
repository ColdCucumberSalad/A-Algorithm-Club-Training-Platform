# 不同链接的同题核验

题名解析成功后，系统在已有提交的题目中查找同名候选（忽略大小写、空白、全半角及 A. / E、等题号前缀）。即使选择自动解析模式，同名候选也会调用当前全站配置的 AI 服务，比较两个链接的实际题面、样例和约束。仅标题相同不构成合并依据。

AI 明确确认同题后保留原链接作为别名，提交关联到同一个题目。明确不同则保持独立。两类明确结论按题目对及当时题名缓存；无法联网、AI 未配置、格式错误或证据不足时不合并、不扣奖，保留题名并进入题名待处理列表，错误注明“同题核验”，可重新解析重试。

同一用户不能重复提交相同的规范化链接。不同链接即使已经确认同题，也可保存为独立提交记录，但同一用户只能有一条有效记录：按首次提交时间、编号排序，保留最早未被驳回的记录，其余标注“重复题目”且不计分。各条记录保留自己的提交链接；修改材料不改变首次提交顺序，切换到另一道题则在新题队列中按修改时间排位。

重复记录可编辑、可删除（包括归档学期的重复记录），编辑后若前序记录仍有效则继续保持无效。正常有效记录的编辑、删除仍遵循原有截止和归档规则。最早有效记录被本人删除或管理员整条驳回时，自动递补下一条重复记录；被驳回的记录不参与递补，除非后续纠正重交。不同用户的提交互不挤占。

撤回仅由无效记录支撑的每日签到和自然周连签奖励；同日仍有有效提交则保留签到。递补恢复材料的原审核状态、原积分及实际被撤回的签到金额，不因配置变动多发；新记录此前未获奖则按正常规则发放。余额已花掉时允许审计欠额，不自动回收物品。普通删除/驳回的回收预览会计入同日递补，避免无须撤回时仍要求回收物品。

已归档的本站过题凭证同步改用统一标识并去重。合并和奖励撤回在同一事务中执行；失败整体回滚。并发任务与新建提交使用相同的题目标识锁，已完成的合并不会重复扣奖；手工改名或取消解析后迟到结果不生效。

迁移：0045_problem_equivalence、0046_duplicate_submission_priority。迁移只新增字段及判定缓存表，不自动改动历史提交或扣奖。既有题目可从题名工作台重新解析触发检查；新题在首次解析时触发。当前以同名题作候选，不把题名完全不同的题目自动判为同题。


并发写入按用户、学期编号、题目标识的顺序取锁；AI 合并会在变更有效性前锁定所有受影响学期，递补、奖励变化和学期统计在同一事务内完成。

0046 为旧记录以当前提交时间初始化首次顺序。旧版合并已丢失的原链接不作推断，仅有明确来源时回填；未知来源的历史重复记录不会阻挡保留记录编辑。新提交会完整保存原链接。
