# 不同链接的同题核验

题名解析成功后，系统在已有提交的题目中查找同名候选（忽略大小写、空白、全半角及 A. / E、等题号前缀）。即使选择自动解析模式，同名候选也会调用当前全站配置的 AI 服务，比较两个链接的实际题面、样例和约束。仅标题相同不构成合并依据。

AI 明确确认同题后保留原链接作为别名，提交关联到同一个题目。明确不同则保持独立。两类明确结论按题目对及当时题名缓存；无法联网、AI 未配置、格式错误或证据不足时不合并、不扣奖，保留题名并进入题名待处理列表，错误注明“同题核验”，可重新解析重试。

同一用户有多条有效提交时，以提交时间和编号保留最早一条。其余记录和附件保留，标注“重复题目”，停止计分、有效次数和过题统计；撤回仅由该记录支撑的每日签到与自然周连签奖励。当天还有其他有效提交则保留签到。通过现有奖励撤回流水记录实际扣额；余额已花掉时允许欠额，不自动回收已购物品。重复记录不允许编辑或重交，但可按原有删除规则删除。不同用户的提交均保留有效。

已归档的本站过题凭证同步改用统一标识并去重。合并和奖励撤回在同一事务中执行；失败整体回滚。并发任务与新建提交使用相同的题目标识锁，已完成的合并不会重复扣奖；手工改名或取消解析后迟到结果不生效。

迁移：0045_problem_equivalence。迁移只新增字段及判定缓存表，不自动改动历史提交或扣奖。既有题目可从题名工作台重新解析触发检查；新题在首次解析时触发。当前以同名题作候选，不把题名完全不同的题目自动判为同题。
